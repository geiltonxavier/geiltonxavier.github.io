Great Code Starts With Amazing People

Um caderno da Vizir Software Studio, um time e um dos capítulos mais importantes da minha carreira.

Vizir Software Studio · provavelmente 2015–2016

Não lembro exatamente quando este caderno foi feito. Meu melhor palpite é 2015 ou 2016, durante meu período na Vizir Software Studio.

A Vizir foi uma empresa muito importante na minha carreira. Foi lá que conheci muitas pessoas tecnicamente fora da curva — e, talvez mais importante, pessoas genuinamente muito boas.

Os rostos dessas páginas aparecem ao redor de uma frase que ainda faz sentido: Great Code Starts With Amazing People.
